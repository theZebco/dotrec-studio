# dotrec Studio

سایت معرفی **dotrec Studio** — پنل مدیریت استودیوهای عکاسی و فیلم‌برداری.
پروژه‌ی استاتیک با HTML، CSS و JavaScript خالص (بدون فریم‌ورک و بدون build) که روی GitHub Pages منتشر می‌شود.

## صفحه‌ها

| فایل | صفحه |
| --- | --- |
| `index.html` | خانه |
| `plans.html` | پلن‌ها (ماهانه / سالانه) |
| `contact.html` | تماس با ما (فرم سه‌مرحله‌ای) |
| `logo.html` | لوگوی متحرک |

## ساختار

```
css/base.css      فونت‌ها، شیشه‌ی مایع، انیمیشن لوگو، ناوبری و دکمه‌ها (مشترک)
css/<page>.css    استایل اختصاصی هر صفحه
js/main.js        نور شیشه، لنز ناوبری و منوی موبایل (مشترک)
js/plans.js       سوییچ ماهانه / سالانه
js/contact.js     فرم مرحله‌ای و اعتبارسنجی
js/logo.js        پخش دوباره‌ی انیمیشن لوگو
assets/fonts      فونت کلمه (Kalameh)
assets/glass      نقشه‌های جابه‌جایی شیشه‌ی مایع
assets/logo       لوگوها و favicon
```

فونت Bodoni Moda از Google Fonts بارگذاری می‌شود.

## اجرا روی سیستم

هر سرور استاتیکی کافی است، برای نمونه:

```bash
npx serve .
```

## نکته‌ها

- فرم تماس فعلاً فقط در مرورگر کار می‌کند و پیام را جایی ارسال نمی‌کند؛ برای ارسال واقعی باید به سرویسی مثل Formspree یا API خودتان وصل شود.
- مقادیر داخل `[ ]` (قیمت‌ها، ایمیل، ساعات پاسخ‌گویی و …) جای‌نگهدار هستند.
